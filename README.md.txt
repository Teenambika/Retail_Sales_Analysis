# Retail Sales Analysis

## Project Overview

This project focuses on analyzing retail sales data to understand sales performance,customer behaviour,product performance,
returns,discount and profitability.

Python was used for data cleaning,SQL was used for data analysis,Excel was used to create an interactive dashboard.

## Tools Used

-Python(Pandas) - Data cleaning and manipulation

-SQL(MySQL) - Data analysis and querying

-Excel - Interactive dashboard and visualization

## Data Formate

-CSV

## Dataset

The dataset contains retail sales information,
including:

-Order ID

-Order Date

-Customer ID

-Customer Name

-Age

-Age Group

-Region

-City

-Product Category

-Product Name

-Quantity

-Unit Price

-Discount

-Sales Amount

-Profit

-Shipping Cost

-Payment Method

-Customer Satisfaction

-Return Flag

-Order Status

-Days to ship

## Data Cleaning with Python

Python and Pandas were used to clean and prepare the dataset.

The cleaning process included:

-Handling duplicate values

-Checking and handling missing values

-Handling inconsistent date formats

-Standardizing gender and order status values

-Identifying and handling negative numeric values

-Checking and handling invalid age values

-Creating a clean dataset for further analysis
